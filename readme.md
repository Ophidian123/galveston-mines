# Galveston Mines

## The Game

The Galveston mines is a procedurally generated runner style game tat takes inspiration from the Roblox game Doors.
This project was created on godot and is planned be compleated in 8 weeks for a full release, but expect it to be later
rather than earlier

## The Lore

The runner/main character is Bruce Cambell

He was urban exploring and stumbled across some abandonded mines, but when he went inside and walked a little bit,
he couldn't get back out!

So Bruce started running, and found that he could slide and run forever

There were rooms to this, every room he passed, it was the same lenght, and the doors were 8 inch thick metal.
You would only use those either to keep something in, or to keep something out.....
